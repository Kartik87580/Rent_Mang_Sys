# 🏢 RentManager — Personal Rent Management System

For full documentation, architectural overview, and setup details, please refer to the root [README.md](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure .env
cp .env.example .env

# 3. Initialize Neon PostgreSQL schema
npm run db:init

# 4. Start local development server
npm run dev
```
